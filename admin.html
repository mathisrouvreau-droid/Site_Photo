                          Connecter GitHub

                          une seule fois

                          Pour publier des photos depuis cette page, il faut une clé d'accès personnelle à ton dépôt. Elle reste uniquement dans ce navigateur et ne donne accès qu'au site.

                          1. Ouvre la page de création d'une clé GitHub.
                          2. Token name : MR VISUALS admin · Expiration : 1 an.
                          3. Repository access : « Only select repositories », puis choisis Site_Photo.
                          4. Permissions → « Repository permissions » → Contents : Read and write. Rien d'autre.
                          5. Clique sur Generate token, copie la clé (elle commence par github_pat_) et colle-la ci-dessous.

                          À ajouter

                          Pour chaque photo, choisis sa collection et décris ce qu'on y voit en une phrase (utile à Google Images). Elles apparaîtront en tête de leur collection.
